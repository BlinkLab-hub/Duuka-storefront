# Duuka Storefront

A responsive online shop landing page for the Ugandan market, built with plain HTML and CSS. No frameworks and no JavaScript.

## Features

- Sticky header with a search bar, account links and a cart badge
- Hero banner with floating, animated product images
- Shop-by-category grid with inline SVG icons
- Featured product cards with discounts, ratings and prices in UGX
- Deals, "Why shop with us", newsletter and footer sections
- Fully responsive for desktop, tablet and phone
- Accessible: ARIA labels, keyboard focus styles and `prefers-reduced-motion` support

## Project Structure

```
duuka-storefront/
├── index.html
├── styles.css
└── product and hero images (.png)
```

## Built With

- HTML5
- CSS3 (Grid, Flexbox, keyframe animations, `clamp()`, media queries)
